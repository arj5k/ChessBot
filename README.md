This is a chess computer you can play against created using PyTorch. To move pieces, you can drag and release, or you can click to select and put down. Press enter to reset the game and switch which color you are playing as.

Each turn, the computer picks the move that maximizes how advantageous the next position of the game will be for it - it does this by comparing a numerical value each position has known as its "evaluation." The best chess computer (i.e. the computer that is able to return the most accurate evaluations of any given chess position) is known as StockFish. Our program learned to predict what StockFish would evaluate any given position by feeding the computer datasets that included given chess positions and their corresponding StockFish rating.
